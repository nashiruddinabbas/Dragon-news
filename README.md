# Dragon News 📰

Dragon News is a modern news portal web application built with **React 19** and **Vite**. It features a clean user interface, fast performance, and dynamic news rendering.

---

## 🚀 Features

* **Dynamic News Display:** Browse news by categories and view detailed news articles.
* **Modern UI:** Styled with **Tailwind CSS (v4)** and **DaisyUI** components.
* **Marquee Effects:** Breaking news ticker using `react-fast-marquee`.
* **Responsive Design:** Fully optimized for Mobile, Tablet, and Desktop screens.

---

## 🛠️ Tech Stack

* **Frontend:** React (v19), Vite
* **Styling:** Tailwind CSS, DaisyUI, React Icons
* **Routing:** React Router (v7)
* **Utilities:** Date-fns (for date formatting), React Fast Marquee

---

## 📦 Installation & Setup

Follow these steps to run the project locally on your machine:

### 1. Clone the Repository
```bash
git clone [https://github.com/nashiruddinabbas/Dragon-news.git](https://github.com/nashiruddinabbas/Dragon-news.git)
cd Dragon-news-main
2. Install Dependencies
Make sure you have Node.js installed, then run:

Bash
npm install

3. Run the Development Server
Bash
npm run dev
Open http://localhost:5173 in your browser to view the app.

📜 Available Scripts
In the project directory, you can run:

npm run dev - Runs the app in development mode.

npm run build - Builds the app for production.

npm run lint - Lints the code for errors.

npm run preview - Previews the production build locally.
